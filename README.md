# vibe-AI_Robot_Odyssey

## Prompt:
```
You are an award-winning creative web designer, AI educator, robotics engineer, and senior frontend developer.

Create an immersive, full-screen interactive educational website inspired by the concept of a futuristic voyage and interactive route map.

Do NOT copy any existing website's source code, copyrighted graphics, logos, text, or exact visual assets.

Instead, create an original interactive learning experience.

# CORE CONCEPT

Transform a traditional AI/robotics curriculum into an immersive futuristic journey.

The learner is not browsing chapters.

The learner is navigating through an AI-and-robotics world.

Each destination on the map represents an important capability required to build an autonomous intelligent robot.

The learning journey progresses through:

Generative AI

↓

Multimodal AI

↓

AI Agents

↓

Computer Vision

↓

Robot Sensors

↓

Robot Control

↓

Embodied AI

↓

Vision-Language-Action

↓

Autonomous Robots

↓

Final Robot Project

The interface should feel like a combination of:

- futuristic robot control center
- AI research laboratory
- autonomous robot navigation system
- interactive technology exhibition
- digital learning journey
- mission-control interface

Do NOT make the website look like a normal LMS, online course, or corporate website.

# FULL-SCREEN EXPERIENCE

Create a full viewport application:

100vw × 100vh

Avoid conventional webpage scrolling on desktop.

The main screen should behave like a large interactive AI learning map.

The user navigates the curriculum by moving through this map.
```
